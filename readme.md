## Lab Tooling

🛠️ Protocol languages, lab operating systems, SDKs and MCP servers that agents act through.

- \[2026-09\] ![MCP](https://img.shields.io/badge/MCP-1f6feb) [LabMCP](https://github.com/K-Dense-AI/lab-instrument-mcps) - MCP servers for real instruments with safety limits, read-only modes, audit trails and a simulator per instrument; its Opentrons server is tested against a simulator and not yet verified on hardware. [package](https://pypi.org/project/labmcp-opentrons/)
- \[2026-08\] ![Framework](https://img.shields.io/badge/Framework-1f6feb) ![MCP](https://img.shields.io/badge/MCP-1f6feb) ![Vendor-Reported](https://img.shields.io/badge/Vendor--Reported-bc4c00) [Model Hardware Standard](https://www.anthropic.com/news/model-hardware-standard-research-preview) - Driver specification with discoverable read and write primitives and natural-language device limits that lets agents operate instruments such as microscopes, liquid handlers and robotic arms; an application-only research preview, not yet open source, whose integration results are reported by Anthropic and its partners rather than independently verified. Anthropic, "Previewing the Model Hardware Standard," Anthropic blog 2026. [preview](https://www.modelhardwarestandard.com/)
- \[2026-07\] ![MCP](https://img.shields.io/badge/MCP-1f6feb) ![Liquid-Handling](https://img.shields.io/badge/Liquid--Handling-2da44e) [plr-mcp](https://github.com/di-omics/plr-mcp) - MCP server exposing a PyLabRobot liquid handler, plate reader, thermocycler and heater-shaker, running in simulation by default with one environment variable to target real hardware.
- \[2026-05\] ![Framework](https://img.shields.io/badge/Framework-1f6feb) ![Closed-Loop](https://img.shields.io/badge/Closed--Loop-1f6feb) ![Liquid-Handling](https://img.shields.io/badge/Liquid--Handling-2da44e) ![Preprint](https://img.shields.io/badge/Preprint-bc4c00) [IvoryOS](https://arxiv.org/abs/2605.03205) - Natural-language closed-loop control of a mobile liquid handler through MCP and the IvoryOS orchestration layer, where an agent ran a 60-trial accuracy optimisation; documented in a community hackathon report. Roy et al., "From Knowledge to Action: Outcomes of the 2025 Large Language Model (LLM) Hackathon for Applications in Materials Science and Chemistry," arXiv 2026. [code](https://github.com/ivoryos-ai/IvoryOS)
- \[2026-04\] ![MCP](https://img.shields.io/badge/MCP-1f6feb) ![Liquid-Handling](https://img.shields.io/badge/Liquid--Handling-2da44e) [OpenLabAI](https://github.com/nygmeta/OpenLabAI) - MCP servers for Opentrons, Hamilton, Biomek and Cellario that give no raw hardware access and never move a robot without explicit per-run approval.
